# Bots support

Before opening a request, update Bots to the latest image and review the in-app **Help** page and README troubleshooting section.

For bugs and support requests, [open a GitHub issue](https://github.com/DotumZane/Bots/issues/new/choose). Include:

- Unraid OS version
- Bots image digest or update date
- Monitor type (product, HTTP, or TCP)
- Relevant container log lines with passwords, tokens, email addresses, and private URLs removed
- Exact steps that reproduce the problem

Use GitHub's private vulnerability-reporting feature for security issues rather than a public support ticket.
